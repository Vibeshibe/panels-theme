Panels is a static Hugo theme. You keep your content in Git and serve the generated files wherever you like.

## Content first

The theme provides real article URLs, RSS, projects, and an album collection. The page remains readable with JavaScript disabled. Theme selection, filtering, tabs, code-copy controls, and the image viewer are small progressive enhancements.

## A familiar workflow

```sh
hugo new content posts/my-first-note/index.md
hugo server --buildDrafts
```

> [!NOTE]
> Each page bundle can keep its own images alongside `index.md`.

Read the [component showcase]({{< relref "/components" >}}) for the supported content components.
